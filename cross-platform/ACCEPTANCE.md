# 实机网络验收（尚未执行）

Windows 10/11 x64、macOS 13+ Intel / Apple Silicon 分别执行。使用可恢复的测试网络，不使用正在承担唯一远程控制通道的主机作首次验收。

| 场景 | 必须满足 |
|---|---|
| 初始状态 | 记录出口节点 ID、DNS 设置、路由和 LAN 设备可达性 |
| 普通启用 | UI 从 starting 到 active；系统 DNS 请求命中本地解析器；国内 A 地址真实路由为物理接口 |
| 海外网站 | 解析规则不变，流量仍经原 Exit Node，节点 ID 不变 |
| LAN / Tailnet | NAS、屏幕共享、`.local`、Tailnet 名称正常；100.64/10 不被本地覆盖 |
| DNS 超时 / NXDOMAIN / 空回答 | 显示 degraded / 失败；不标成功、不更换 Exit Node |
| 国内服务器失效 | 仅在配置的国内服务器间重试；无请求发送给其他 DNS |
| DNS 私网注入 / CNAME 循环 | 拒绝回答和对应路由，不破坏旧有效规则 |
| CDN 地址更新 | 新 IP 路由先验证，旧 IP 租约到期删除；两个域共享 IP 时不提前删除 |
| IPv6 / HTTPS hint | 受管理域名没有未经验证的 IPv6 路径；海外 IPv6 保持原行为 |
| TCP / 截断 | UDP TC 后可通过 TCP 完成；端口 53 被占用时拒绝启用且无残留 |
| 浏览器独立 DoH | 明确显示系统检查范围；关闭独立 DoH 后核验浏览器实际流量 |
| Wi-Fi / 网关变化 | 撤销本次配置、显示原因；不继续使用旧网关，不改新出口 |
| 睡眠恢复 / Tailscale 暂停 | 状态不虚假保持成功，可停止恢复后重新启用 |
| 杀死 worker | supervisor 撤销 DNS 和拥有的路由；原 DNS、Exit Node 可用 |
| 停止 / 系统重启 | 停止只删本程序资源；重启自动任务重新预检，不复用过期 DNS 缓存 |
| 文件 / NRPT 被第三方修改 | 不强删，报告恢复未完成 |
| 中文用户名 / 路径含空格 | GUI 配置、UAC、安装和停止均正常，无路径截断 |

保存每个平台的系统版本、Tailscale 版本、构建 SHA、前后路由/DNS快照和失败复现日志后，才可把本 Alpha 标记为实机验收通过。
